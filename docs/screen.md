# 개발 규칙

## 폴더 규칙
- 공통 컴포넌트: src/shared/ui/common
- 레이아웃 컴포넌트: src/shared/ui/layout
- 차트 컴포넌트: src/shared/ui/charts
- 새 유형 생기면 src/shared/ui 안에 자동 생성

## 화면 ID 규칙
### 형식
[포탈코드]-[카테고리코드]-[화면코드]-[순번]
예시: DV-DF-RG-001

### 규칙
1. 모든 코드는 영문 대문자 2자리
2. 순번은 3자리 숫자 (001부터 시작)
3. 구분자는 하이픈(-)으로 통일
4. 형식은 영문-영문-영문-숫자로 고정
5. depth 3단계 이상은 핵심 카테고리로 압축
6. 같은 카테고리는 항상 동일한 코드 유지
7. 기존 코드와 중복 금지
8. 새 화면 ID 생성 시 목록으로 알려줄 것

### 포탈 코드
- CO: Common
- DV: Dev 포탈
- CS: Customer 포탈
- SP: Support 포탈
- AD: Admin 포탈

## 화면 개발 원칙
### 이미지 참고 방식
- 첨부 이미지는 레이아웃/구조 파악용으로만 참고
- 이미지 그대로 구현하지 말 것
- Ant Design에 최적화해서 재해석

### Ant Design 최적화 원칙
- Ant Design 기본 컴포넌트 우선 사용
- 없는 경우에만 커스텀 구현
- Props와 variant 최대한 활용
- 불필요한 CSS 커스텀 최소화

### 화면 구현 순서
1. Ant Design 컴포넌트로 구조 잡기
2. 이미지 참고해서 배치 조정
3. 테마/컬러 적용
4. 다크/라이트 모드 확인
