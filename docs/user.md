# 로봇 학습 플랫폼 <forge>

## 사용자 유형
<고객>
1. 모델 사용자: 로봇 AI 모델을 실제 현장에서 운영/활용 하는 사람, 로봇 적용이 필요한 작업 및 현장 정보, 폼팩터 등 최소한의 기술 요건을 제공

<개발>
1. 프로젝트 책임자: 모델 사용자의 요구 또는 내부 의사결정에 따라 학습 계획을 수립하고 프로젝트 전반의 딜리버리를 책임짐
2. 데이터 엔지니어: 할당된 데이터 수집 작업에 따라 실물 연결, 일괄 업로드 또는 사용자 영상 변환 등을 통해 데이터를 확보, 확보된 데이터를 기반으로 증강 또는 합성 데이터 생성 수행
3. 모델 개발자: 요청 받은 작업에 대해 데이터 선정/정련하고 모델 학습 및 검증 수행

<지원>
1. 시뮬레이션 엔지니어: 새로운 로봇 폼팩터, 정교한 환경이 필요할 경우 시뮬레이션 구성을 지원
2. 기반 모델 관리자: RFM및 World Foundation Model, 동작 모델 등을 검토하고 등록/관리
3. 실물 로봇 관리자: 데이터 수집 및 검증 수행을 위한 로봇 포함 물리 장비 관리자

<관리>
1. 인프라 관리자: 학습 수행을 위한 GPU, 컨테이너 및 데이터/모델 저장소 관리
2. 플랫폼 관리자: 사용자, 권한 등 일반적인 플랫폼 관리를 수행

## 사용자 정책
- 플랫폼 관리자만 사용자 그룹(ex. 고객, 개발, 지원, 관리)과 플랫폼 내 역할 설정을 할 수 있다. (단, 데이터 엔지니어, 모델 개발자 설정은 불가)
- 프로젝트는 프로젝트 책임자만 생성할 수 있다.
- 프로젝트 책임자는 자신의 프로젝트에 속한 멤버들의 역할(데이터 엔지니어 또는 모델 개발자)을 설정할 수 있다.
