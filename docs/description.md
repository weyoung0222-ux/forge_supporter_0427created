## Description 모드 스펙

- 사이드 바 및 화면 번호, 하이라이트 표시는 최상단 Layer로 표시
- 하이라이트 표시는 콘텐츠 영역 width값과 무관하게 노출

### Floating 버튼
- 위치: 모든 화면 우측 하단 고정
- 버튼명: Description
- 실제 플랫폼 UI와 구분되는 스타일 적용
- on/off가 구분되는 스타일 적용

### Description ON 동작
- 기존 모든 인터랙션 그대로 유지
- 화면 주요 영역에 ① ② ③ 원형 번호 뱃지 표시
  (번호는 화면 상단 좌측부터 시계방향 순서)
- 우측 사이드바 자동으로 열림

### 클릭 연동 (핵심)
- 화면의 번호 뱃지 선택 시
  사이드바에서 해당 영역 설명으로 자동 스크롤
  + 해당 영역 하이라이트 표시
- 선택 해제 시 하이라이트 해제

### Description OFF 동작
- 번호 뱃지 모두 사라짐
- 하이라이트 모두 해제 (화면 영역 내 하이라이트도 모두 해제)
- 사이드바 닫힘
- 기존 모든 인터랙션 그대로 유지


### 사이드바 구성
- 화면명
- 화면 ID (`docs/forge.md` 참조)
- 화면 설명
- 구분선
- 영역별 디스크립션 목록
  ① 영역명
    - 역할
    - 사용자 동작
    - 연결 화면
  ② 영역명
    - 역할
    - 사용자 동작
    - 연결 화면
  (이하 동일)

### 자동화 규칙
- 새 화면 생성 시 영역 번호와 디스크립션 초안 자동 생성
- 기존 화면 수정 시 자동 업데이트
- 영역 번호는 화면 상단 좌측부터 시계방향 순서로 자동 부여

### 적용 범위
- 모든 화면 공통 적용
- GNB/LNB 제외
- 다크/라이트 모드 모두 지원
